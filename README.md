# ✦ Nova Calculator

A modern, attractive, and user-friendly calculator built using HTML, CSS, and JavaScript.

## ✨ Features

- 🎨 Beautiful dark theme with gradient background
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 💯 Percentage calculations
- 🔄 Positive/negative number toggle
- ⌫ Delete and clear buttons
- 📜 Recent calculation history
- ⌨️ Keyboard support
- 📱 Responsive mobile-friendly design
- ⚡ Fast and lightweight
- 🚫 Division-by-zero error handling

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
Nova-Calculator/
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `calculator.html` in your web browser.
4. Start calculating!

## ⌨️ Keyboard Shortcuts

| Key | Action |
|---|---|
| 0–9 | Enter numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| Enter | Calculate result |
| Backspace | Delete last digit |
| Escape | Clear calculator |
| % | Percentage |
| . | Decimal point |
